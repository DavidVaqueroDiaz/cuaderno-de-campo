# Cuaderno de campo

Prototipo visual de una aplicación para redactar y generar informes de metrología
industrial a partir de los datos exportados por el software de medición.

**No es un producto.** Es un borrador de trabajo: ninguna función es real, no guarda
nada, no calcula nada, y todos los clientes, máquinas y valores que aparecen son
inventados. Sirve para hablar del flujo de trabajo antes de construir nada.

## Qué se puede ver

- Panel con indicadores y gráficos
- Alta de un trabajo, paso a paso
- Editor del informe por bloques
- Ficha permanente de una máquina con su histórico
- Biblioteca de bloques y plantillas
- Informe de ejemplo de ocho páginas

## Cómo publicar cambios

El archivo `index.html` es autónomo: un solo fichero, sin dependencias externas
salvo la tipografía. Se sustituye y se hace `git push`.
